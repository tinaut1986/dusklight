- What's New: before installing an update, see what changed in every version between yours and the new one, betas included.
- Changelog (Settings → Interface): every release of your channel, newest first.
- Check for Updates Now (Settings → Interface) works during a game too: it shows what changed and installs the update, which starts the next time you open Dusklight.
- Release notes show in the menu language when the release has them, in English otherwise.
- Scroll the notes with the D-pad or stick, and by pages with L1/R1.
- Touch: drag lists and menus with a finger to scroll them, like on a phone; a drag no longer presses the button under it.
- Touch: with Steam's "Touchscreen Native Support" on, the mouse arrow hides while you use your fingers and a gold ring marks each touch.
- Display Mode (Settings → Video) replaces "Toggle Fullscreen": Windowed or Fullscreen, kept for the next start, and a window keeps its size and position. In Steam's Game Mode it is always fullscreen, so the game uses the whole Steam Deck screen.
