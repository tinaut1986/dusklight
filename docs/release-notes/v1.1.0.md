- First stable release of this fork, based on Dusklight 2.0.3 plus its latest fixes.
- Menus, settings and prompts in Spanish, chosen in Settings → Prelaunch → Menu Language.
- Updates come from this fork and install from the start screen when running from an AppImage (Steam Deck), checked before replacing the game.
- Beta Updates (Settings → Interface) also offers beta builds.
- New upstream options: No Hit Stun (Gameplay) and Infinite Epona Stamina (Cheats).
- Discord Rich Presence is off by default.
