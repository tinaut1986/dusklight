- First build of this fork, based on Dusklight 2.0.3 plus its latest fixes.
- Menus, settings and prompts in Spanish. Pick the menu language in Settings → Prelaunch → Menu Language; new languages only need a file in res/l10n.
- Updates come from this fork. Running from an AppImage (Steam Deck), the start screen installs them for you and checks the download before replacing the game.
- Beta Updates (Settings → Interface) also offers beta builds.
- New upstream options: No Hit Stun (Gameplay) and Infinite Epona Stamina (Cheats).
- Discord Rich Presence is off by default.
